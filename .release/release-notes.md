# FlowDrop 1.12.0

- Đổi tên thiết bị trên Windows và Android; lưu qua lần mở lại, cập nhật tên trong Wi-Fi, giữ ID và phiên truyền.
- Windows tự kiểm tra khi mở và mỗi 6 giờ. Kiểm tra thủ công báo rõ có/chưa có bản mới hoặc lỗi mạng.
- Có bản mới: chọn Cập nhật ngay / Để sau; chỉ tải sau khi đồng ý, chờ phiên truyền kết thúc, kiểm tra chữ ký/SHA-256 rồi cài đè và mở lại.
- Explorer: chọn một/nhiều file hoặc thư mục → Send to → FlowDrop. Windows 11: Show more options → Send to. File thêm vào cùng cửa sổ để chọn máy nhận.

Cài đè, không gỡ bản cũ. APK versionCode 13 giữ khóa ký gốc. Kênh cập nhật: https://github.com/Melbournejr/FlowDrop_IOS/releases/latest/download/latest.json.

Kiểm chứng: kiểm thử mạng Node/Java, luồng cập nhật có lựa chọn và cửa sổ Windows trong Wine đã qua. Chưa thử bản 1.12 trên thiết bị Windows/Android thật. Xem FlowDrop-Kiem-chung-1.12.json để biết phạm vi.
